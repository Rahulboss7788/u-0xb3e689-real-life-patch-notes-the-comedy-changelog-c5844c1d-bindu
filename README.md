A one-line software patch note for a bug in daily life, in the terse register of a real release note: the phone battery that drops from 20% to 1% the second you leave the house. Running `main.ts` writes exactly that line to `/output/entry.txt` and verifies it is 1–160 characters.

## Run it

```sh
node main.ts
```
